## Arquitectura propuesta y migración

Núcleo local modular **Karen Core** con contrato versionado para perfiles, sesiones, memoria, configuración, permisos, eventos, tareas y auditoría. SQLite puede almacenar datos locales; adaptadores Ollama, API Karen y OpenClaw conservan sus contratos. Empezar por API loopback autenticada y contratos de lectura, tras decidir propiedad de sesión y migración. Pet y clásica deben poder funcionar por separado mientras se migra. Probar interoperabilidad y reconexión antes de retirar almacenes existentes. Nunca compartir secretos a través de historial ni exponer administración por defecto.
